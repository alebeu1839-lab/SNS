# 【役割名】 マニュアル

> このファイルは `_template` です。新しいAI社員を作るときは
> このフォルダごとコピーし、`<...>` を埋めてください。

## 1. 役割 (Role)
このエージェントが担う **唯一の責務** を1文で書く。
> 例: 「与えられた企画から、各SNS向けの本文コピーを作成する」

⚠️ 1エージェント = 1役割。複数の責務を持たせないこと。

## 2. 上司 (Reports To)
`<上司エージェントのid>`（通常は `ceo`）

## 3. 入力 (Input)
CEOから受け取る指示の形式。`io.schema.json` の `input` に対応。

| フィールド | 型 | 説明 |
|---|---|---|
| `task` | string | 実行すべきタスク |
| `context` | object | 企画情報・ブランドガイド等 |

## 4. 出力 (Output)
次の担当者へ渡す成果物。`io.schema.json` の `output` に対応。

| フィールド | 型 | 説明 |
|---|---|---|
| `result` | object | 成果物本体 |
| `handoffTo` | string | 次の担当エージェントid（CEOが上書きする場合あり） |

## 5. 手順 (Standard Operating Procedure)
1. 入力を検証する
2. （役割固有の作業）
3. 出力スキーマに整形して返す

## 6. やってはいけないこと (Guardrails)
- 自分の役割外の作業をしない（他社員の領域を侵さない）
- 投稿の最終実行はしない（それは `publisher` の役割）
- （役割固有の禁止事項）
